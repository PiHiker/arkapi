Fund
Paste / Scratchpad API • Live on Signet test network only

Park intermediate text or JSON without turning ArkAPI into a file host.

Store agent notes, workflow state, or JSON checkpoints for a bounded amount of time and get back a short public URL. Retrieval is always JSON, not HTML, with expiry and noindex headers by default.

2 sats / call
POST /api/paste
GET /v1/p/{id}
Default TTL: 24h

Input Shape

Send exactly one content field plus an optional TTL.

  • content for UTF-8 plain text
  • json for structured JSON that ArkAPI stores compactly
  • ttl_seconds to override the default retention window
  • Response includes the short id, public url, and exact expires_at

Safety Model

This endpoint is intentionally constrained so it behaves like a scratchpad, not generic public hosting.

  • Public retrieval is JSON-only
  • No HTML rendering or custom MIME types
  • No raw executable download behavior
  • Expiry is enforced and expired pastes disappear
  • Responses include noindex and nosniff headers

Example Request

curl -X POST https://arkapi.dev/api/paste \ -H "Authorization: Bearer ak_your_token" \ -H "Content-Type: application/json" \ -d '{"json":{"step":"extract","urls":["https://example.com"],"notes":"follow up tomorrow"},"ttl_seconds":3600}' | jq

Use a funded token from the Fund page. The response gives you a short public URL under /v1/p/{id}.

Example Create Response

{ "success": true, "data": { "id": "k3m8v2q4r7tz", "url": "https://arkapi.dev/v1/p/k3m8v2q4r7tz", "content_kind": "json", "size_bytes": 74, "ttl_seconds": 3600, "expires_at": "2026-04-02T13:00:00Z" }, "cost_sats": 2, "balance_remaining": 498, "endpoint": "/api/paste" }

Example Public Fetch

curl https://arkapi.dev/v1/p/k3m8v2q4r7tz | jq
{ "id": "k3m8v2q4r7tz", "content_kind": "json", "content": "{\"step\":\"extract\",\"urls\":[\"https://example.com\"],\"notes\":\"follow up tomorrow\"}", "size_bytes": 74, "created_at": "2026-04-02T12:00:00Z", "expires_at": "2026-04-02T13:00:00Z" }

Good Uses

  • Save agent checkpoint JSON between steps
  • Hand off extracted links or notes to another tool or human
  • Park a temporary result without wiring object storage
  • Share a short-lived text blob with a teammate during triage
